# Исследование вычислительной инфраструктуры для ИИ-ассистента в закрытом контуре

## Описание проекта

Данный репозиторий содержит результаты предпроектного исследования по выбору вычислительной инфраструктуры для развертывания корпоративного ИИ-ассистента в изолированном контуре (Air-Gap) АО «ЦНИИ «Буревестник».

В рамках работы были:
- выделены 4 группы пользователей с различными сценариями работы;
- выполнены математические расчёты пиковых нагрузок (закон Литтла, распределение Пуассона);
- рассчитаны требования к видеопамяти (VRAM) для моделей Llama-3-8B, Qwen2.5-VL-7B/72B, Qwen-2.5-32B;
- проведён сравнительный анализ трёх конфигураций (на базе A40, L40S, A100);
- выполнен экономический расчёт (CAPEX/OPEX/TCO);
- разработан интерактивный дашборд для визуализации результатов.

## Интерактивный дашборд

[Запустить дашборд](dashboard.html)

Дашборд содержит 4 вкладки:
1. **Технические характеристики чипов** — VRAM, пропускная способность, FP16/FP8 TFLOPS.
2. **Бенчмарки инференса LLM** — производительность Llama-3-8B и Qwen2.5-VL-72B.
3. **Экономика (TCO и Энергопотребление)** — затраты первого года для всех конфигураций.
4. **Интерактивный симулятор нагрузок** — позволяет подбирать конфигурацию под разные сценарии.
